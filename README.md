# Prod-Follow-up

**Production Progress Follow-up（生产进度跟进）**

[![在线演示](https://img.shields.io/badge/在线演示-访问页面-brightgreen)](https://liuyang042.github.io/Prod-Follow-up/)

## 📖 项目简介

本项目为**生产进度跟进**的操作指引与培训教材网站，旨在帮助团队系统化地管理从交货需求分析、生产进度监控到品质异常处理的全流程。内容涵盖TORAY与NON-TORAY两大业务线的具体操作步骤，并集成多个SAP功能模块与Excel分析工具。

🔗 **在线演示**: [https://liuyang042.github.io/Prod-Follow-up/](https://liuyang042.github.io/Prod-Follow-up/)

## ✨ 核心功能模块

### 一、PPC 交货需求资料
- 展示当前系统交期现状与原因分析。
- 提供**TORAY**与**NON-TORAY**交货计划资料（含Excel附件下载）。

### 二、CPO 交货清单
- **STOCK + WIP（TORAY）**：四步操作流程，从处理交货需求、分析库存与WIP数据，到整合发送交货清单。
- **STOCK + WIP（NON-TORAY）**：三步操作流程，同样涵盖需求处理、库存/WIP分析及清单发送。

### 三、生产进度跟进方法
- 通过SAP系统功能代码（如`ZSOHPP143`、`ZSOHPP190`）跟进急单与APP缸号。
- CPO分析WIP工单状态，覆盖染厂、整理车间跟进。
- 提供多个染整工单分析工具入口。

### 四、品质异常跟进处理
- QTC测试结果查询与异常处理（功能代码：`ZSOHQM031`）。
- 6级布问题查询与进度通报（功能代码：`ZSOHQM010`）。
- 督查QA颜色NG数据（功能代码：`ZSOHPP063`）。

### 五、QR单特别跟进数据
- 每天邮件通报WIP情况。
- 每周通报QR单完成情况。

### 六、准时交货率沟通
- 与PPC密切沟通预计交货情况，协助统计准时交货率。

## 🛠️ 技术工具

- **SAP系统**：使用多个定制功能代码进行数据查询与跟进。
- **Excel分析工具**：包含多个启用宏的工作簿（.xlsm），用于交货需求分析、库存与WIP数据处理。
- **前端技术**：HTML/CSS/JavaScript构建响应式操作指引页面。
